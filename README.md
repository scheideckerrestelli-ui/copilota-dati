# copilota-dati

Mappe del [Copilota IA](https://scheideckerrestelli-ui.github.io/copilota-ia/): un file
per regione, servito da GitHub Pages e scaricato dall'app su richiesta.

Sta separato dal repo dell'app perché i dataset pesano centinaia di MB e in git non si
cancellano più: così il repo del codice resta leggero, e questo si può azzerare quando
la storia si gonfia senza toccare l'app né il suo indirizzo.

Geometrie © collaboratori **OpenStreetMap**, licenza **ODbL** — derivate dagli estratti
regionali di [download.openstreetmap.fr](http://download.openstreetmap.fr/extracts/europe/italy/).
